\# 📄 ATS Resume Tracker



AI-powered resume matching system that analyzes resumes against job descriptions using \*\*TF-IDF keyword extraction\*\* and \*\*bigram analysis\*\*.



🔗 \*\*Live Demo:\*\* \[https://ats-resume-tracker.runasp.net](https://ats-resume-tracker.runasp.net)



\---



\## ✨ Features



| Feature | Description |

|---------|-------------|

| 📤 \*\*Resume Upload\*\* | Upload PDF and TXT resumes with automatic text extraction |

| 💼 \*\*Job Management\*\* | Create, update, and delete job descriptions |

| 🎯 \*\*AI Matching\*\* | TF-IDF keyword extraction with bigram analysis for accurate matching |

| 📊 \*\*Resume Analyzer\*\* | Score resumes on format, length, skills, experience, and education |

| 💡 \*\*Smart Suggestions\*\* | Get actionable recommendations to improve your resume |

| 📈 \*\*Visual Dashboard\*\* | Real-time match scores with animated progress circles |
